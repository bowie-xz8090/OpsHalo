## Reporting Security Issues

If you believe you have found a security vulnerability in **OpsHalo (this repository)**, please report it promptly.

We review legitimate reports and work to fix issues that affect SSH, SFTP, AI Agent execution, approval, and credential safety.

如果您认为在 **OpsHalo（本仓库）** 中发现了安全漏洞，请尽快报告。

我们会审查合理报告，并尽快修复影响 SSH、SFTP、AI Agent 执行、审批和凭据安全的问题。

Please use the private security advisory flow at https://github.com/bowie-xz8090/OpsHalo/security/advisories/new. If that is unavailable, open an issue without including exploit details or credentials.

对于敏感漏洞，请优先使用 GitHub Private Security Advisory；不要在公开 Issue 中粘贴密码、私钥、Token 或可直接利用的攻击细节。
